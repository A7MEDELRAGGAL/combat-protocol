# Combat Protocol — Implementation Status v1.9 (BR-0 Loot & Inventory)

**التاريخ:** 26 أكتوبر 2026
**الإصدار:** `1.9.0`
**الإضافة:** أول طبقة حقيقية من باتل رويال — غنائم، حقيبة محدودة السعة، والتقاط فعلي في الميدان.

---

## 1. ما تم تنفيذه

### 1.1 نموذج الغنائم — `js/loot-data.js`

أربع درجات ندرة بأوزان صريحة:

| الندرة | الوزن | المضاعف | اللون |
|---|---|---|---|
| شائع | 60 | ×1.00 | `#9aa08f` |
| نادر | 27 | ×1.15 | `#5b8fba` |
| ملحمي | 10 | ×1.30 | `#a06bd0` |
| أسطوري | 3 | ×1.45 | `#d9a45c` |

- 12 قالب غنيمة: ذخيرة (4 أنواع)، دروع (2)، علاج (2)، قنابل، 3 مرفقات.
- 8 أسلحة قابلة للسقوط بأوزان مختلفة (SR-9 أسطوري بوزن 2 فقط).
- `createLootTable(seed, count)` **حتمية**: نفس البذرة = نفس المحتوى، فالمباراة قابلة للإعادة.

### 1.2 الحقيبة — `js/inventory.js`

- سعة 120 وحدة، كل غرض له `size`.
- الذخيرة والعلاج والقنابل **تتكدس** في خانة واحدة (الزيادة لا تستهلك وزناً إضافياً).
- `addItem` لا يرمي استثناءً أبداً: يرجّع `{added:false, reason:"full"}` عند الامتلاء.
- سلاحان أساسيان + مسدس احتياطي كحد أقصى.
- الدرع مُقيَّد بـ 100.

### 1.3 صناديق الميدان — `js/loot.js`

- 28 صندوقاً في وضع الباتل رويال، موزعة ببذرة مشتقة من عدد المباريات.
- كل صندوق مكعب بلون ندرته + نواة مضيئة + دوران وطفو خفيف.
- كشف تلقائي لأقرب صندوق داخل **2.4 متر**.

### 1.4 الربط في اللعب

- `E` لالتقاط أقرب غنيمة.
- تأثير فوري: ذخيرة → احتياطي السلاح، درع → `player.armor`، علاج → `player.health`، قنبلة → `grenades.charges`، سلاح → تبديل فوري.
- رسالة HUD عند الالتقاط، ورسالة «الحقيبة ممتلئة» عند الرفض.
- سطر ملخص أعلى يمين الشاشة: عدد الخانات + الدرع + القنابل.

### 1.5 البوتات

`battleRoyale.enemyCount` من **12 → 20** بوتاً، مطابقاً لهدف BR-0 في `ROADMAP.md`.

## 2. التحقق

```text
npm test       → # tests 55 | # pass 55 | # fail 0   (كان 45)
npm run verify → All smoke checks passed
```

اختبارات جديدة (10) تغطي:
1. حتمية جدول الغنائم لنفس البذرة.
2. صلاحية كل غرض (id/name/size/amount/rarity/kind).
3. كل درجات الندرة معروفة.
4. الأسطوري أقل من 20% فعلياً.
5. الحقيبة تبدأ فارغة.
6. تكديس الذخيرة لا يستهلك خانات.
7. الحقيبة الممتلئة ترفض بلطف.
8. الدرع لا يتجاوز 100.
9. سلاحان أساسيان + مسدس.
10. `canFit` يطابق السعة الحرة.

فحوص المتصفح الجديدة:
- `loot crates spawn from the seeded table` → 10 صناديق.
- `proximity detection finds a crate` → true.
- `pickup moves the item into the inventory` → 0 → 1 عنصر، والمتبقي 9.
