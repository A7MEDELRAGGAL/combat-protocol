## 1. ما تم

### حركة الشخصيات (الأعداء المرئيون)

قبل: الأرجل تتأرجح فقط، والجسم يتحرك ككتلة واحدة.

بعد:

| العنصر | الحركة |
|---|---|
| الأرجل | تأرجح كامل مرتبط بالسرعة (حتى 0.7 راديان) |
| الذراع الحرة | تتأرجح عكس الأرجل بمعامل 0.75 |
| ذراع السلاح | حركة محدودة 0.18 حتى يبقى التصويب مستقراً |
| الجسم | صعود/هبوط 3.5 سم مع كل خطوة |
| الميل | يميل للأمام حتى 0.12 راديان عند الجري |

النتيجة: من مسافة، العدو يمشي بخطوات واضحة، ويجري بميل جسم ووتيرة أسرع، بدل انزلاق كتلة صلبة.

### أنميشن السلاح (من v1.12)

- التلقيم: نزول 14 سم + ميل 25°/50° ثم عودة.
- الكرواتش: نزول إضافي 5 سم.
