# Combat Protocol — Visual Realism Plan v1.15

## الهدف

رفع الـprototype من شكل تقني قابل للعب إلى **field build** أكثر احترافية وواقعية،
مع الحفاظ على WebGL محلي، الأصول الإجرائية الأصلية، ووضع low/safe للأجهزة الضعيفة.

## ما تم في هذه الحزمة

- هوية واجهة جديدة: طبقات زجاجية داكنة، تباين أفضل، grain/scanline خفيف، أزرار وحالات
  أكثر وضوحاً، وHUD مقسّم إلى وحدات تكتيكية قابلة للقراءة.
- خامات Procedural محسّنة للأرض والحاويات والصناديق: اختلاف roughness، خدوش، seams،
  أرقام شحن، زوايا معدنية، مسامير، وطبقات clearcoat بسيطة.
- إضاءة أكثر عمقاً: key/fill/rim balance، ظلال high quality، ونسيم غبار deterministic.
- آثار إصابة على الأسطح: pool ثابت من 48 decal يعاد استخدامه، مع اتجاه مطابق لسطح
  الاصطدام وعمر محدود حتى لا يتراكم أو يسبب تسريباً.
- الحفاظ على قابلية الاختبار: لا طلبات شبكة، لا أصول خارجية، وquality low يقلل الغبار
  ويحافظ على مسار safe mode.
- benchmark محلي يقيس FPS وdraw calls وpixel ratio في high/low عبر `npm run benchmark`.

## معايير القبول

1. شاشة القائمة والـHUD يظهران بشكل مقروء على 1440×900 و390×844.
2. الساحة تحتفظ بالتصادم، الإطلاق، الأسلحة، الأعداء، والخرائط الخمس.
3. لا تظهر أخطاء Console أو WebGL في المسار الطبيعي، ويظل fallback الآمن يعمل.
4. `npm test` و`npm run verify` يمران بالكامل.
5. `npm run benchmark` يطبع قياس high/low بدلاً من التخمين.
6. تقرير التوازن لا يعلن سلاحاً مهيمناً.

## المرحلة التالية

1. تحسين نماذج الأعداء إلى silhouettes بمفاصل ومواد مختلفة دون rig خارجي.
2. إضافة decals بيئية اختيارية (زيت/ماء/أوساخ) مع نفس الميزانية العمرية.
3. إضافة LOD/instancing للأصول المتكررة إذا تجاوز benchmark ميزانية الرسم.
4. بعد تثبيت الشكل، الانتقال إلى TDM المحلي الحقيقي ثم multiplayer authoritative كما في `ROADMAP.md`.

## ملاحظة واقعية

هذا pass يرفع جودة الـprototype داخل قيود Three.js والأشكال الإجرائية الحالية. الوصول إلى
واقعية AAA كاملة يحتاج نماذج PBR أصلية، normal/roughness maps مرسومة، animation rig،
VFX وصوت إنتاجي؛ لذلك لا نخلط بين هذا التحسين وبين إنتاج لعبة نهائية.
