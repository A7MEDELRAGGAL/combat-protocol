# Combat Protocol — Implementation Status v1.12 (Weapon Handling)

**التاريخ:** 26 أكتوبر 2026
**الإصدار:** `1.12.0`
**الإضافة:** أنميشن تلقيم وكرواتش على موديل السلاح.

---

## 1. ما تم

### 1.1 أنميشن التلقيم

قوس واحد ناعم لكل عملية تلقيم:

```js
reloadProgress = 1 - (reloadEnd - now) / reloadTime
reloadArc      = sin(reloadProgress * π)     // 0 → 1 → 0
view.y        -= reloadArc * 0.14
view.rot.x    += reloadArc * 0.25
view.rot.z    += reloadArc * 0.50
```

النتيجة: السلاح ينزل 14 سم ويميل 25° للأمام و50° جانبياً في منتصف التلقيم، ثم يعود لوضعه.

### 1.2 أنميشن الكرواتش

عند الانخفاض (`Ctrl` / `C`): السلاح ينخفض 5 سم إضافية ويبقى منخفضاً طوال فترة الكرواتش، فيتوافق مع انخفاض الكاميرا 0.45م.

### 1.3 التحقق

فحص متصفح حقيقي يقيس إزاحة الموديل أثناء التلقيم:

```
reload animation dips the viewmodel — {"dipping":-0.361,"rest":-0.29}
```

أي أن السلاح نزل **0.071** وحدة أثناء التلقيم ثم عاد إلى -0.29. الفحص يفشل لو الفرق أقل من 0.005.
