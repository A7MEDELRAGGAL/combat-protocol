# Combat Protocol — World & Deployment Pass v1.18

## الهدف

تجهيز اللعبة للعرض العام: نسخة ثابتة ترفعها على أي سيرفر، مع خرائط Battle
Royale أكبر ومبانٍ حقيقية وأنيميشن مشي أوضح.

## 1. نسخة النشر

```powershell
npm run build
```

ينتج `dist/` (≈2.35 MB) وتحتوي فقط على:

```text
index.html  css/  js/  vendor/  _headers  _redirects  robots.txt  .nojekyll
```

- لا تحتاج Node أو backend؛ أي استضافة ثابتة تعمل.
- جاهزة لـNetlify (`netlify.toml`)، Vercel (`vercel.json`)، Cloudflare Pages،
  GitHub Pages، أو nginx.
- دليل كامل في `README-DEPLOY.md`.
- تم اختبارها عبر `python -m http.server` وChrome: Harbor Town، 20 بوتاً،
  8 مبانٍ، **0 أخطاء Console و0 طلبات فاشلة**.

## 2. نظام المباني

`world.js` أصبح يبني بيوتاً إجرائية:

- جدران بسماكة 24 سم، باب بعرض 1.56–1.8 م، نافذة/نافذتان على الواجهة
  والخلف، نوافذ جانبية، إطار باب، مظلة مدخل، درجة، أربع زوايا معدنية،
  fascia للسطح، وبارابيت.
- سطح مستوٍ + وحدة تكييف/تهوية على السطح.
- داخلية: طاولة ورف وأضواء سقف بسيطة للمباني الكبيرة.
- كل جدار/سطح له collider منفصل، والمبنى يظهر في الـMinimap ككتلة.
- التوليد يحترم حدود الساحة، الحاويات، الـspawns، ونقاط المهام؛ لا يضع
  مبنى فوق ممر spawn.

## 3. Harbor Town — خريطة BR الثالثة

- حدود **80×72** بدل 68×48، مع 20 spawn و5 POI:
  الصف الشمالي، الصف الجنوبي، سوق البلدة، الأرصفة، الساحة المركزية.
- 8 بيوت موزعة على شارعين، مع حاويات ومستودعات على الأطراف.
- بيئة ساحلية مختلفة (ضباب، إضاءة، ألوان أرضية).
- ظهرت في `BR_MAPS` وتُختار من اللوبي مثل بقية الخرائط.

### إصلاح حدود BR

`meridianExpanse` و`duneBasin` كانا يستخدمان حدود 68×48 بينما الحاويات
تمتد إلى ±32؛ أصبحا **72×68**، فلم تعد هناك أصول خارج الجدران.

## 4. الأنيميشن

- إيقاع الخطوات يتغير مع السرعة (مشي/جري) بدل تردد واحد.
- الركبة تنثني على النصف الخلفي من الخطوة، والذراع الحرة تتأرجح عكس الساق.
- ميل أمامي أثناء الجري، تأرجح جانبي خفيف، وتنفس في وضع الوقوف.
- ذراع السلاح تحافظ على اتجاه التصويب مع حركة بسيطة.
- الموت المفصلي من v1.16 محفوظ.

## 6. الحدود الحالية

- المباني أحادية الطابق؛ لا سلالم داخلية ولا أسطح قابلة للصعود.
- الأثاث الداخلي بسيط (طاولة/رف) وليس غرفاً متعددة.
- لا توجد أبواب متحركة؛ المداخل فتحات ثابتة.
- الـloot يتجنب الجدران ويضع نسبة من الصناديق داخل المباني، لكنه ليس موزعاً
  حسب نوع الغرفة بعد.
- اللعبة ما زالت prototype محلي؛ multiplayer شبكي لم يُنفذ.
